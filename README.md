### 👨‍💻 About me

I'm a **Senior Software Engineer** from **Pune, India** with **5+ years** of building full-stack products in React, Node.js and NestJS, currently at **Calfus**.

Lately I've been building **AI agents** that catch production errors and raise fixes on their own, and that help my team decide what to work on each day.

- 🤖 **Now building:** AI agents for incident response and engineering prioritization (Python, Temporal, LLMs)
- ⚙️ **Day to day:** Kafka-driven microservices, GCP, React & Node.js upgrades, rock-solid tests
- 🌱 **Interested in:** distributed systems, AI agent workflows, and data structures & algorithms
